How to install project dependencies:

    1.  Create and activate a virtual environment for the project (vs code recommended).
    2.  Open terminal and navigate to the project's directory.
    3.  Use the 'Requirements.txt' file by running 'pip install -r Requirements.txt' 
    (-r flags means read-file).

The Requirements file is generated by running 'freeze > [fileName]' which lists 
all the installed packages in the text file created.
